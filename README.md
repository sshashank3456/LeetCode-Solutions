# LeetCode Solutions

This repository contains my LeetCode problem solutions, automatically synchronized from LeetCode to GitHub using a custom Chrome extension.

## 🚀 LeetCode AutoSync

**LeetCode AutoSync** automatically uploads my accepted LeetCode solutions to this repository after submission.

### How it works

```text
LeetCode
   ↓
Submit Solution
   ↓
Submission Accepted
   ↓
AutoSync detects the solution
   ↓
Code + Problem Information extracted
   ↓
GitHub API
   ↓
LeetCode-Solutions repository
